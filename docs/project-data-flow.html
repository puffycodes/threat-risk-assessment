Trust boundaries

Internet

Crossed only by flows 3 and 4, both from the Claude Code session. Nothing in the assessment browser or on disk talks to the network directly.

Claude Code session

Agents can only read, search and write files, and search the web. They have no shell. The assessor runs on the session's model, the designer and summarizer on Sonnet.

Workspace files

Plain Markdown on local disk with no access control beyond the OS account. D2–D7 are git-ignored and need a separate backup.

Assessment browser

Loopback HTTP with no authentication. Any local process can read documents through it. Writes need the page's token and Origin.
